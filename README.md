# Harvey & Steph — 2026 Family Goals Dashboard

A private family goals tracker built with Next.js, React, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Editing Goals

All content lives in the `/data` folder as JSON files — no code changes needed:

- `financialGoals.json`
- `travelGoals.json`
- `familyGoals.json`
- `homeProjects.json`
- `visionBoard.json`
- `nextActions.json`

## Deploy to Vercel

Connect this GitHub repo to Vercel and it will auto-deploy on every push.
